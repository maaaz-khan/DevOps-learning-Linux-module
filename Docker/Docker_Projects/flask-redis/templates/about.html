About This Project

Docker & Redis Demo Application

This project was built as part of my DevOps learning journey to demonstrate how modern applications can be containerised using Docker. It combines Flask, Redis and Docker to create a simple, scalable web application that showcases backend development, networking and container orchestration.

🐍 Flask

Flask powers the web application by serving web pages, handling routes and providing REST-style API endpoints.

⚡ Redis

Redis acts as a high-performance in-memory database used for storing counters and application data efficiently.

🐳 Docker

Docker packages the application and its dependencies into portable containers, allowing it to run consistently across different environments.

Technologies Used

Python

Main programming language used to build the application.

Flask

Lightweight Python framework for web development.

Redis

Fast in-memory database for counters and key-value storage.

Docker

Containerises the application and its dependencies.

Docker Compose

Runs multiple services together in a single environment.

HTML & CSS

Creates a responsive and user-friendly interface.
