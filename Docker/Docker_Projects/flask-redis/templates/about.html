About VisitTracker Pro

Simple Visit Tracking Powered by Flask, Redis and Docker

VisitTracker Pro is a small web application built to track page visits, display application statistics and check system health. It was designed and developed by Ma'aaz Khan as part of my DevOps learning journey.

📊 Visit Tracking

The application uses Redis to count and store visits, making it fast and efficient for simple tracking functionality.

💚 Health Checks

The health page checks whether the Flask application and Redis service are running correctly inside the containerised environment.

🐳 Containerised Setup

Docker and Docker Compose are used to run the Flask and Redis services together in a consistent development environment.

Technologies Used

Python

Main programming language used to build the backend.

Flask

Web framework used for routing, templates and endpoints.

Redis

In-memory database used for visit tracking and key-value storage.

Docker

Packages the application and dependencies into containers.

Docker Compose

Runs the Flask and Redis services together.

HTML & CSS

Creates the responsive user interface and page styling.
