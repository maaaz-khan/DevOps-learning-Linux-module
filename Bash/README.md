# Bash Scripting Portfolio

This repository contains a collection of Bash scripts I have built while developing my Linux and DevOps skills.

The goal of these projects is to strengthen my understanding of Bash scripting, Linux system administration, automation, troubleshooting, and core DevOps concepts through hands-on practice.

Rather than simply learning commands, I have focused on building practical scripts that solve real-world problems and demonstrate common scripting techniques used in Linux environments.

## Scripts Included

### arithmetic.sh

A command-line calculator that performs arithmetic operations using user input.

#### Concepts Covered

* Functions
* Arithmetic Expansion
* User Input
* Input Validation
* Case Statements
* Error Handling

#### Features

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero protection
* Integer validation

---

### backup.sh

Creates timestamped backups of text files from a specified directory.

#### Concepts Covered

* File Operations
* Variables
* Directory Validation
* Timestamps
* Exit Codes
* Error Handling

#### Features

* Creates unique backup directories
* Copies `.txt` files automatically
* Counts backed-up files
* Handles missing directories gracefully

---

### file_check.sh

Demonstrates file creation, file writing, and basic file management operations.

#### Concepts Covered

* Directory Creation
* File Creation
* Output Redirection
* Command Substitution

#### Features

* Creates directories automatically
* Generates files dynamically
* Writes timestamps into files
* Displays file contents

### monitor.sh

#### Concepts Covered
