# SAD Servers

This section documents my experience working through challenges from SAD Servers, a hands-on Linux troubleshooting platform designed to simulate real-world system administration, DevOps, and incident response scenarios.

Unlike traditional Linux exercises that focus on learning individual commands, SAD Servers presents realistic problems that require investigation, analysis, and problem-solving to identify and resolve issues on a live Linux system.

## Why SAD Servers?

One of the biggest lessons I've learned during my Linux journey is that knowing commands is only part of the process. The real challenge is understanding how to use those commands to investigate problems, gather information, and identify the root cause of an issue.

SAD Servers provides an excellent environment for developing these skills through practical scenarios based on situations that Linux administrators, DevOps engineers, and Site Reliability Engineers may encounter in production environments.

## Skills Developed

Throughout these challenges, I gained hands-on experience with:

## Key Takeaway

SAD Servers has helped me move beyond simply learning Linux commands and has encouraged me to think like an engineer investigating a real problem.

The platform has strengthened my troubleshooting mindset by teaching me how to gather evidence, analyse information, test assumptions, and systematically work towards a solution.
