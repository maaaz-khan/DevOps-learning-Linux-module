# Level 0 → 1

**Goal:**
The password for the next level is stored in a file called `readme` located in the home directory.

**What I Did:**

Once logged in, I ran `pwd` to confirm I was in the home directory.

I then used `ls` to list the contents of the directory and found a file named `readme`.

Finally, I used the `cat` command to display the contents of the file and retrieve the password for the next level.

```bash
pwd
ls
cat readme
```

**Commands Learned:**

* `pwd` – Displays the current working directory.
* `ls` – Lists files and directories.
* `cat` – Displays the contents of a file.
