# DevOps Learning – Linux Module

This repository contains my practical exercises, notes, and challenge solutions completed throughout the Linux module of the CoderCo DevOps course.

## What I Learned

Throughout this module, I developed hands-on experience with:

* Navigating and managing the Linux file system
* Understanding file permissions and ownership
* User and group management fundamentals
* Process management and system monitoring
* Networking essentials and SSH
* Environment variables and shell fundamentals
* Linux troubleshooting and command-line problem solving
* Security-focused Linux challenges and investigations

## OverTheWire Bandit Journey (Levels 1–20)

I completed the first 20 levels of the OverTheWire Bandit wargame, gaining practical experience in:

* Command-line navigation and file operations
* Text processing using tools such as `grep`, `sort`, `uniq`, and `diff`
* Working with different file formats, encodings, and compression methods including Base64, ROT13, hexadecimal, gzip, bzip2, and tar archives
* Investigating file permissions and ownership to locate restricted files
* Establishing and managing network connections using `nc` (Netcat) and `openssl`
* Using SSH with private keys and non-interactive commands
* Identifying and utilising setuid binaries for privilege escalation exercises
* Applying multiple Linux concepts together to solve increasingly complex challenges
