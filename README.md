## Bash Scripting Projects

As part of my learning journey, I built several Bash scripts to automate common Linux administration tasks and strengthen my scripting skills.

### Scripts Included

* **arithmetic.sh** – Arithmetic calculator using functions, input validation, conditionals, and case statements.
* **backup.sh** – Creates timestamped backups of text files and reports backup statistics.
* **file-manager.sh** – Demonstrates file creation, writing, reading, and directory management.
* **monitor.sh** – Generates system monitoring reports including CPU, memory, disk, uptime, and process information.
* **permissions.sh** – Checks file permissions, ownership, and metadata.
