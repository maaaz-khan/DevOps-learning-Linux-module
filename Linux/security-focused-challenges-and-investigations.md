# Security-Focused Linux Challenges and Investigations

As part of my Linux learning journey, I have worked through several security-focused challenge platforms designed to develop practical problem-solving, troubleshooting, and investigative skills.

These exercises provided hands-on experience with real Linux commands and tools while encouraging a methodical approach to analysing systems, investigating issues, and identifying solutions.

---

## OverTheWire Bandit

One of the most valuable learning resources I have used is the OverTheWire Bandit wargame.

I successfully completed Levels 1–20, with each level introducing new Linux concepts and progressively more challenging problems.

Throughout the Bandit challenges, I gained practical experience with:

* Linux file system navigation
* File discovery and manipulation
* Hidden files and directories
* Text processing and filtering
* File permissions and ownership
* Data encoding and decoding
* Compression and archive formats
* SSH authentication
* Network communication
* Privilege escalation concepts

---

## Investigating File Permissions

Several Bandit levels focused on file permissions and ownership.

These exercises helped me understand:

* How Linux controls access to files
* The importance of least-privilege access
* How ownership affects file accessibility
* The role of special permissions such as setuid

Working through these challenges improved my understanding of Linux security fundamentals.

---

## Working with Encoded and Compressed Data

Many tasks involved identifying and extracting information from:

* Base64 encoded files
* ROT13 encoded text
* Hexadecimal data
* Gzip archives
* Bzip2 archives
* Tar archives

These challenges demonstrated how different file formats are commonly used and how Linux tools can be combined to investigate and process them.

---

## SSH and Secure Access

Bandit introduced me to working with SSH in practical scenarios.

I learned how to:

* Connect to remote systems
* Use SSH keys for authentication
* Work with private and public keys
* Access systems securely without relying solely on passwords

These skills later proved useful when configuring GitHub authentication using SSH keys.

## SAD Server Challenges

I have also completed several challenges from the SAD Server platform, which focuses on troubleshooting Linux systems and investigating unusual behaviour.

Completed challenges include:

### Saint John

Investigated which process was writing to a suspicious log file.

### Saskatoon

Analysed log data to identify suspicious IP addresses and patterns of activity.

### The Command Line Murders

Solved a forensic-style investigation using only Linux command-line tools.

## Why These Challenges Matter

Security-focused Linux challenges provide practical experience that goes beyond simply learning commands.

They encourage:

* Critical thinking
* Problem-solving
* Attention to detail
* Troubleshooting under pressure
* Understanding how Linux systems behave in real-world situations
